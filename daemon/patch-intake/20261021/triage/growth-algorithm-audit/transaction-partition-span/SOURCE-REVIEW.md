# Span partition source review

Exact candidate f418debf52ada8964e7fa58da36b5fef7b361ae2, tree14e035afc396308ec0809e6007cdb1f331d9301f, based canonical9f044190/tree7583. Source-only review; native/compiler/kernel gate pending explicit N1 lease.

The changed private walker takes a mutable span of pointer slots. Both public functions still create and own their local pointer vector; input identities remain const and never reordered. Existing duplicate sorts/checks and failure behavior are unchanged. std::partition places precisely the zero-bit keys in the left span and one-bit keys in the right span at the same LSB-first depth. Stability is unnecessary: subtree membership, leaf hash and depth-tagged parent hash determine the result; original input order did not. Every original async eligibility condition is unchanged because sizes/nonempty subsets are identical.

Each partition completes before either child starts. Child spans are disjoint subranges; recursive writers never touch sibling slots. An async task captures its small span descriptor by value, not a reference to a local descriptor. Each launched future is joined by get, or drained by its std::async future destructor if the right branch throws. Therefore no descendant can outlive the outer public pointer-array storage during success or exception unwinding. No shared per-call mutable cache or worker pool is added; overlapping public calls each allocate their own array.

This removes two recursive pointer-vector allocations/reserves at every internal node. It does not remove public pointer-vector storage, duplicate sorting, hashes, std::async allocations/threads, or the public TransactionRoot duplicate-ID check vector. Partition comparison/visits still scale with key depth. Balanced cumulative pointer-copy allocation was proportional to the number of keys times their branching depth; the replacement needs one O(n) pointer array across recursive workers. Peak old memory depends on tree shape and concurrency and is not blindly claimed n*log(n); unary chains can retain repeated full-size vectors, while balanced serial descent has geometric live scratch.
