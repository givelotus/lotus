# Doged headers-only restart and mainnet sync follow-up

The maintained Dogecoin candidate now has **174 mailboxes** on immutable ABC `1fb7db17c176cdea8a2c60d887891589382ee4e3`. The added patch repairs a real default-work header synchronization stall after restart. Integration source `3047eec50b23b9ad0ceba53e507c034b73ec4efa` and metadata export `59b343a4dcce4259fa8eec8562ec5f0cb2cb3da2` have the same tree, `2b378152efca0ea2c578433f348e71db367202b0`. The preceding 173 mailbox files are byte-identical to the earlier review commit `4b92ebcb`; replay verifies all 174 intermediate trees and mail metadata.

The isolated node had 918,000 indexed headers and 14,942 downloaded block bodies. With default minimum chain work, presync attempted `CBlockIndex::GetBlockHeader` at an AuxPoW headers-only index. That method reads the full proof from the block file, whose position is `(-1,0)` until the block body is downloaded. The older binary repeatedly logged that missing-file failure and did not resume presync.

`HeadersSyncState` needs the starting header's hash, difficulty bits and timestamp. Patch 0174 reconstructs those 80-byte base fields directly from the block index and stores them as `CBaseBlockHeader`. It leaves full AuxPoW proof checking for received headers, serialized wire headers, full-header RPC and Chronik on the existing full-header path. This changes no difficulty, subsidy, Script, AuxPoW commitment or PoW acceptance rule.

The new binary restarted the copied datadir with **no `-minimumchainwork` override**, `-assumevalid=0`, Chronik enabled and Avalanche disabled. Real peers then advanced header presync from 918,000 past **1,001,999** at the recorded observation. The peer advertised height was about 6.4 million; that is peer metadata, not locally validated state. **Accepted block height remains 14,942**, IBD is true, and full-tip synchronization is outstanding. A separate local progress recorder tracks accepted blocks, indexed headers, presync logs, peer count and free disk space in `/tmp/lotus-doged-current-fullsync-20261015/fullsync-progress.jsonl`; it stops the isolated node if free space falls below 30 GiB. Production nodes and datadirs remain untouched.

The Chronik-enabled and disabled daemon/CLI builds pass on the new source. The native binary passes **757/757 cases and 32,967,026 assertions**, including a new headers-only AuxPoW presync regression. Both header-sync cases pass 22 assertions. The new daemon independently passes offline `verifychain 4 1000` and Chronik/RPC/raw-disk parity at five sampled mainnet heights covering 103 transactions, ending at accepted height 14,942. The preceding 17 functional, 14 PoW, 144 Avalanche, 3 RTT, Rust and GPU results are retained with their earlier source identities; patch 0174 changes only header presync and its native test. Full commands, hashes, tree checks and the exact observation are in [follow-up evidence](evidence/doged-current-abc-fullsync-followup-20261015.json).
