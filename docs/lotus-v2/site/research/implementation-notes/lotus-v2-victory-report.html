  1. Per-Tx Snapshot Rebuild Bottleneck ($O(B \cdot M \log U)$ $\to$ $O(B + M)$):
  2. Previously, PublishMempoolSnapshot was called after every individual transaction inside AcceptToMemoryPool and removeForBlock, cloning the entire SmtNode UTXO root and re-encoding hex for all $M$ mempool transactions on every single tx (200,000 SmtInsert calls for a 200-tx batch!).

  4. Batch Ceiling Lift (MAX_RAWTX_BATCH_COUNT 50 -> 1,000) & 2-Phase Ephemeral View Reuse:
  5. Eliminated redundant Phase-2 re-validation in submitrawtxbatch under the same cs_main + mempool.cs lock scope.
