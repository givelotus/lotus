# Private V2 explorer coverage, 2026-10-15

This measures existing tests against frontend source from monorepo `39ac976c` and native/Chronik source `86201398e3df61605c2eb2d09c201ce774013e7f`. Collection uses a fresh monorepo worktree at `a6a0f471`; its `explorer/v2` tree is byte-identical to `39ac976c`. A separate native worktree and new build/target directories preserve existing builds, nodes, and data. No application source or test was changed. This baseline predates authority repair `cfdc16f435` and the subsequent node C++ changes; their new counter/authority branches are not covered by this collection. Passing tests for those newer changes must be recorded separately, and an updated coverage run needs their final exact source pin.

[Evidence and collection helpers](../../daemon/tests/evidence/explorer-coverage-20261015/) retain source/binary hashes, logs, compressed exports, mapped denominators, and uncovered ranges. `summary.json` is generated by `summarize.py`. This is execution coverage of selected tests, not path coverage, MC/DC, whole-program coverage, protocol acceptance, or a performance measurement. The native-to-Rust CXX boundary is explicitly unmeasured below.
