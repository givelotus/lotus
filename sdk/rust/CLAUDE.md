# Bitcoin Suite — Agent Guide

This is a Rust workspace of libraries for Bitcoin-like blockchain interaction (BCH, XEC, XPI/XTG, XRG). All project governance, documentation policies, and coding standards live in `docs/CONSTITUTION.md` — read it before planning any change. Every plan MUST include a "Documentation Updates" section identifying which docs need updating per the decision matrix in §1. Run `cargo test` before marking any task complete and report the result.

Monorepo integration decisions and test coverage are recorded in [AGENTS.md](AGENTS.md) and [README.md](README.md).
